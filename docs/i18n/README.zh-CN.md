Studio Method 是一款面向 macOS 和 Windows 的桌面应用，作为 Superpowers、BMAD 等先进 AI 工作方法的集中枢纽。

## 它是什么

它组织并连接产品团队的整个生产流程，将从最初的构思、PRD 撰写到最终代码的各个环节统一起来。

在平台内，每位团队成员都通过适配自己角色的界面，在同一个项目中协作：

- **PM（产品经理）**：在标准化的 PRD 中梳理并管理产品需求。
- **PD（产品设计师）**：将需求范围转化为符合项目规范的原型。
- **Dev（开发者）**：接收已结构化、可直接进入实施队列的交接内容。

角色之间的交接在应用内持续进行。当某个阶段被标记为完成或可交给下一角色时，项目会自动进入下一位负责人的任务队列。

在整个过程中，通过斜杠命令（`/`）触发的集成 AI 智能体会为任务执行提供支持。它们会应用已配置的方法论，协助撰写文档、生成原型并指导代码编写，确保对设计系统和团队规则的最佳遵循程度。

## 隐私与安全

**你的项目和文件都保存在你自己的电脑上。** Studio Method 不会将你的项目内容（PRD、原型、代码、文件）发送到任何服务器——所有内容都直接读取并保存到你在本机磁盘上选择的文件夹中。

唯一会经过外部服务器（Supabase）的数据，是**账号登录**所必需的信息（邮箱和密码，用于访问应用）。项目内容不会存储在那里。

如果你连接了某个 AI 模型（Claude、本地 Ollama 服务器，或其他兼容 OpenAI API 的服务），你在聊天中发送的消息会被分享给该 AI 提供方以生成回复——这与任何使用 AI 的应用一样。如果不连接模型，智能体将无法工作，但应用的其余功能仍可正常使用。

## 安装方法

1. 前往本仓库的 **[Releases](../../../../releases)** 页面。
2. 下载最新版本中适合你系统的安装包：
   - **Mac**：`.dmg` 文件
   - **Windows**：`.msi` 或 `.exe` 文件
3. 打开安装包，按提示完成安装。

**操作系统安全提示：** 由于应用尚未完成付费的数字签名认证（Apple/Microsoft），macOS 和 Windows 可能会提示"无法识别的开发者"。这是正常现象——如需继续打开：
- **Mac**：右键点击应用 →「打开」→ 在弹出的窗口中确认「打开」。
- **Windows**：在 SmartScreen 蓝色提示页面点击「更多信息」→「仍要运行」。

## 安装后的第一步

1. 创建账号或登录。
2. 选择你的角色（PM、PD 或 Dev）。
3. 进入 **设置 → AI 模型**，连接一个模型（推荐使用你的 Claude 订阅），这样智能体才能正常回复。
4. 新建一个项目，并输入 `/` 探索聊天功能。
